# 🎮 Game Labirin Berbasis Greenfoot

## 📌 Deskripsi
Game Labirin Berbasis Greenfoot adalah game 2D yang dikembangkan menggunakan framework Greenfoot berbasis Java. Game ini terinspirasi dari permainan klasik seperti Pac-Man, di mana pemain mengendalikan karakter utama untuk menjelajahi labirin, mengumpulkan poin, serta menghindari musuh (ghost).

Pemain harus menyelesaikan setiap level dengan strategi, ketepatan gerakan, dan kecepatan dalam mengambil keputusan untuk mencapai kemenangan.

## 🎮 Fitur Game
- Karakter utama yang dapat dikendalikan pemain
- Musuh (ghost) dengan pergerakan otomatis
- Sistem skor (score)
- Sistem poin (collectible item)
- Level permainan
- Menu utama (Start, Help, Exit)
- Kondisi menang dan kalah (Game Over & You Win)
- Efek suara (sound effect)

## 🧠 Teknologi yang Digunakan
- Java (Object-Oriented Programming / OOP)
- Greenfoot Framework
- Visual assets (images & sprites)
- Audio / sound system Greenfoot

---

## 🚀 Cara Menjalankan Game

1. Buka aplikasi **Greenfoot**
2. Klik **Open Project**
3. Pilih folder project game
4. Tunggu hingga semua class termuat
5. Pastikan world utama adalah `menu_play_game`
6. Klik tombol **Run** untuk memulai game
7. Gunakan tombol **Reset** jika ingin mengulang permainan


## 🎮 Cara Bermain

- Gunakan kontrol yang tersedia untuk menggerakkan karakter utama
- Kumpulkan poin yang ada di dalam labirin
- Hindari musuh (ghost) agar tidak kalah
- Selesaikan setiap level untuk memenangkan permainan

## 🎯 Tujuan Game
Game ini dibuat untuk:
- Mempelajari konsep Pemrograman Berorientasi Objek (OOP)
- Implementasi Java dalam bentuk game interaktif
- Melatih logika, strategi, dan algoritma dasar
- Memahami event-driven programming menggunakan Greenfoot
