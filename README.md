# 🎮 Labirin Game

A 2D maze game developed using the **Greenfoot Framework** and **Java**. Inspired by classic arcade games such as **Pac-Man**, players navigate through a labyrinth, collect points, avoid enemy ghosts, and complete each level to achieve victory.

---

## ✨ Features

- 🎮 Player character with keyboard controls
- 👻 Enemy ghosts with automatic movement
- ⭐ Score and collectible point system
- 🗺️ Multiple game levels
- 🏠 Main menu (Start, Help, Exit)
- 🏆 Win and Game Over conditions
- 🔊 Sound effects

---

## 🛠️ Tech Stack

- Java
- Object-Oriented Programming (OOP)
- Greenfoot Framework

---

## 🚀 Installation

1. Clone this repository.

```bash
git clone https://github.com/ys124xkd/Labirin.git
```

2. Open the project in **Greenfoot**.
3. Wait until all classes have loaded.
4. Ensure `menu_play_game` is selected as the main world.
5. Click **Run** to start the game.

| Key | Action |

## 🎯 Gameplay

- Navigate through the labyrinth.
- Collect all available points to increase your score.
- Avoid enemy ghosts to stay alive.
- Complete each level to progress.
- Reach the final objective to win the game.
